# سجل السويتشات والنقاط الشبكية

- يسجل كل سويتش مرة واحدة في `department_data/telecom/networkSwitches` بمعرّف ثابت ورقم فريد وطابق وموقع ومسار اتصال وعدد منافذ.
- يختار الحاسب السويتش المسجل ثم رقم منفذه؛ لا يجوز تكرار المنفذ على السويتش نفسه، ويجب أن يقع ضمن عدد المنافذ المعلن.
- رقم النقطة الشبكية مستقل عن رقم منفذ السويتش. يمكن حفظ المنفذ دون نقطة ثم فتح سجل السويتش وإضافة رقم النقطة لاحقاً.
- يمنع تكرار رقم النقطة بين منافذ السويتشات المسجلة.
- لا يسمح بتقليل عدد المنافذ إذا كان هناك جهاز أو نقطة موصولة بمنفذ خارج العدد الجديد.
- الأجهزة القديمة ذات `switchNumber` النصي تبقى كما هي ويمكن ربطها لاحقاً بالسجل باستخدام `switchId`.
- كتابات الفنيين تمر عبر طلب الاعتماد الحالي؛ المدير يكتب مباشرة. القراءة للمستخدمين المسجلين وفق قواعد المشروع الحالية.

## تنبيه تشغيلي
هذه ضوابط تحقق على مستوى واجهة التطبيق ومسار الاعتماد. يجب إجراء اختبارات Emulator قبل نشر القواعد أو اعتمادها للإنتاج، وإضافة تحقق خادمي ذري عند تعدد المستخدمين المتزامنين لتجنب سباق حجز المنفذ.
