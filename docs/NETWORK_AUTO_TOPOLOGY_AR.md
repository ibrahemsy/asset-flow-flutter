# مخطط الشبكة التلقائي

## طريقة العمل
- يحدد المستخدم لكل حاسب مكتبي أو محمول مسار الاتصال: سيرفر داخلي أو إنترنت خارجي أو غير متصل.
- عند اختيار مسار اتصال، يسجل رقم السويتش والطابق الموجود فيه السويتش ورقم المنفذ.
- تنشئ شاشة الشبكة المخطط تلقائياً، وتقسم الحواسيب بحسب مسار الاتصال ثم الطابق ثم رقم السويتش.
- الحقول الجديدة اختيارية للحفاظ على توافق سجلات الأجهزة القديمة؛ تظهر الحواسيب التي لم تُحدّث ضمن عدد غير محدد.

## حدود الدلالة
المخطط يعرض التوصيلات المسجلة ولا يثبت أن الجهاز أو المنفذ متصل الآن. التحقق الفعلي يحتاج تكاملاً منفصلاً مع SNMP أو منصة مراقبة الشبكة، مع صلاحيات وصول مناسبة.

## CI
تولد خطوة إعداد المنصات Web وAndroid قبل البناء. أزيل مرجع مجلد assets غير الموجود من pubspec.
