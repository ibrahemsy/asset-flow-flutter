# نظام إدارة الأصول والعهدة — دائرة الاتصالات

تطبيق Flutter لإدارة الأجهزة، بطاقات العهدة، الحركات، الصيانة، شبكة المقاسم، التقارير، Excel، وGoogle Sheets.

## التشغيل
```bash
flutter pub get
flutterfire configure
flutter run
```

## التجهيز الكامل
راجع **SETUP.md** (Firebase + Google Sheets API + OAuth + Supabase).

## Google Sheets داخل التطبيق
شاشة **التقارير**:
- تصدير الجرد إلى Google Sheets
- تقرير شامل على Google Sheets
- تصدير/استيراد Excel

## مدير النظام
رئيس دائرة الاتصالات — اعتماد الطلبات والإعدادات.
